# 环境配置

配置文件为项目根目录 `.env`；从 `.env.example` 复制得到。不要提交真实 API Key。所有路径均相对项目根目录。

| 配置项 | 必须 | 默认/示例 | 用途 | 不配置会怎样 |
|---|---:|---|---|---|
| `LLM_PROVIDER` | 完整决策必需 | `dashscope` | 选择 `dashscope` 或 `openrouter` | LLM 初始化失败 |
| `DASHSCOPE_API_KEY` | 使用 DashScope 必需 | 无真实默认值 | Qwen 兼容 API Key | 无法生成 Agent 方案 |
| `DASHSCOPE_MODEL` | 否 | `qwen3.7-flash` | DashScope 聊天模型 | 使用代码默认模型 |
| `OPENROUTER_API_KEY` | 使用 OpenRouter 必需 | 无真实默认值 | OpenRouter Key | 该 provider 无法使用 |
| `OPENROUTER_MODEL` | 否 | `openai/gpt-4o-mini` | OpenRouter 聊天模型 | 使用默认模型 |
| `DATABASE_URL` | 否 | `sqlite:///data/supply_chain.db` | 本地业务数据 SQLite | 使用该默认文件 |
| `UI_BACKEND_MODE` | 否 | `direct` | `direct` 进程内调用或 `api` 通过 FastAPI 调用 | 保持兼容的进程内模式 |
| `BACKEND_API_URL` | API 模式必需 | `http://127.0.0.1:8000` | Streamlit 访问后端的地址 | 使用本机默认地址 |
| `BACKEND_API_TIMEOUT_SECONDS` | 否 | `180` | Agent 长请求的 HTTP 超时 | 使用 180 秒 |
| `API_HOST` / `API_PORT` | 否 | `127.0.0.1` / `8000` | FastAPI 监听地址和端口 | 仅本机访问 8000 端口 |
| `RAG_KNOWLEDGE_DIR` | 否 | `data/knowledge` | 知识文件目录 | 找不到知识源或使用默认目录 |
| `RAG_PERSIST_DIR` | 否 | `data/vector_store` | Chroma 索引目录 | 使用默认目录 |
| `RAG_COLLECTION_NAME` | 否 | `enterprise_knowledge` | Chroma collection 名 | 使用默认 collection |
| `RAG_EMBEDDING_PROVIDER` | 否 | `local` | `local` 或 `dashscope` embedding | 使用本地 embedding |
| `RAG_EMBEDDING_MODEL` | 否 | `BAAI/bge-small-zh-v1.5` | embedding 模型 | 使用默认模型 |
| `RAG_MIN_SCORE` | 否 | `0.25` | 召回最低相似度分数 | 使用默认阈值 |
| `AGENT_MAX_TOOL_CALLS` | 否 | `6` | 一轮只读工具调用预算 | 使用默认值（代码上限 12） |
| `AGENT_TOOL_TIMEOUT_SECONDS` | 否 | `8` | 单个工具超时秒数 | 使用默认值（代码上限 30） |
| `AGENT_MAX_REFLECTION_ROUNDS` | 否 | `2` | 反思最大轮数 | 使用默认值（代码上限 3） |
| `HITL_CHECKPOINT_DB` | 否 | `data/workflow_checkpoints.sqlite` | LangGraph 暂停/恢复检查点 | 使用默认文件 |
| `HITL_APPROVAL_TTL_HOURS` | 否 | `24` | 审批有效期 | 使用默认值 |
| `HITL_DIRECTOR_COST_THRESHOLD` | 否 | `10000` | 更高金额触发审批角色门槛 | 使用默认值 |
| `HITL_APPROVER_BINDINGS` | 审批演示建议配置 | 见模板 | 本地邮箱与审批角色绑定 | 审批身份无法按预期解析 |
| `HITL_CURRENT_ACTOR_EMAIL` | 审批演示建议配置 | `manager@example.com` | 服务端本地审批人 | UI 不能自行切换身份 |
| `AGENT_TRACE_PATH` | 否 | `data/agent_traces.jsonl` | 运行/工具/错误事件日志 | 使用默认文件 |
| `LANGSMITH_TRACING` | 否 | `false` | 启用 LangSmith 运行追踪和实验 | 只保留本地 JSONL trace |
| `LANGSMITH_API_KEY` | 启用 LangSmith 时必须 | 无真实默认值 | LangSmith 身份凭证 | LangSmith 追踪/评测拒绝启动 |
| `LANGSMITH_PROJECT` | 否 | `supply-chain-control-tower` | 运行 trace 项目名 | 使用代码默认值 |
| `LANGSMITH_EVAL_DATASET` | 否 | `supply-chain-control-tower-regression` | 版本化场景数据集 | 使用代码默认值 |
| `LANGSMITH_EXPERIMENT_PREFIX` | 否 | `supply-chain-agent` | 实验名称前缀 | 使用代码默认值 |
| `APP_ENV` / `AGENT_VERSION` / `AGENT_PROMPT_VERSION` | 否 | `local` / `interview-v1` / `v1` | Trace 筛选和实验版本标识 | 使用默认标识 |
| `AGENT_MAX_LONG_TERM_MEMORIES` | 否 | `5` | 单次召回结果经验的上限 | 使用默认值 |
| `MEMORY_FEEDBACK_USERS` | 录入结果反馈必需 | `planner@example.com,analyst@example.com` | 允许提交结果反馈的邮箱白名单 | 反馈提交会被拒绝 |
| `EVAL_MIN_OVERALL_SCORE` | 否 | `80` | 离线评测通过线 | 使用默认值 |
| `EVAL_MAX_BASELINE_DROP` | 否 | `3` | 回归允许下降分数 | 使用默认值 |

## 其他真实配置

- DashScope Base URL 可用 `DASHSCOPE_BASE_URL` 覆盖；默认是兼容模式地址。
- OpenRouter Base URL 可用 `OPENROUTER_BASE_URL` 覆盖；默认 `https://openrouter.ai/api/v1`。
- LangSmith 首选 `LANGSMITH_*` 配置；旧的 `LANGCHAIN_TRACING_V2`、`LANGCHAIN_API_KEY`、`LANGCHAIN_PROJECT`、`LANGCHAIN_ENDPOINT` 仍兼容。未启用不会阻止本地运行。
- `LANGSMITH_HIDE_INPUTS/OUTPUTS=true` 可隐藏上传的运行输入/输出。演示数据可以保留以便查看 trace；连接真实企业数据前应开启隐藏或实现字段级脱敏。
- `.streamlit/config.toml` 已将 `server.fileWatcherType` 设为 `none`，用于避免部分 `transformers/torchvision` 可选依赖被 Streamlit 文件监视器探测时报错。修改源码后请手动重启 Streamlit。

## 当前不存在的配置

仓库没有 Redis、外部 PostgreSQL、独立 Vector DB 服务、消息队列、`MOCK_MODE` 开关或 Docker。FastAPI 当前为同步等待 Agent 结果的单机服务边界，尚未引入任务队列或分布式 worker。
