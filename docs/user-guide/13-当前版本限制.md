# 当前版本限制

本章用于防止把演示能力误认为生产能力。

## 数据与外部系统

- 产品、库存、需求、供应商、采购单、审批、记忆和结果反馈默认存放在本地 SQLite 文件 `data/supply_chain.db`。
- 采购执行由 `src/procurement_adapter.py` 的本地适配器模拟；不会创建真实 ERP/SRM 订单，也不更新真实 WMS/TMS。
- 没有外部实时事件流、定时监控、消息队列、Webhook 或并发任务调度。
- `demo/demo.py` 是纯静态展示；其中的图表、风险和“RAG 证据”均为预置内容。

## LLM 与 RAG

- 完整决策依赖外部 DashScope 或 OpenRouter 模型服务；无 Key、配额耗尽或网络异常会影响生成方案。
- RAG 使用本地 Chroma 向量索引，需手动 ingest；没有在线文档上传、审核、版本审批或自动重建服务。
- 召回证据是辅助信息，不保证合同/制度内容正确、最新或适用于真实业务；仍需人工审阅。
- 当前没有独立 reranker 服务、检索运营后台或生产级数据权限隔离。

## 审批、安全与身份

- 有真实的本地 LangGraph interrupt/checkpoint/resume 调用链，但身份由环境变量模拟，不是 SSO、企业 RBAC 或电子签名。
- 风险门禁、参数模型和只读工具白名单降低了误操作风险；并不构成完整的安全审计、权限体系、预算体系或合规认证。
- 审批批准时会重新校验业务快照，但系统不处理真实企业环境中的分布式并发、锁、消息重放和跨服务事务。

## 前端与可观测性

- “决策档案”只展示当前 Streamlit 会话中刚生成的方案，不是全量历史运行检索平台。
- 运行事件默认写 JSONL，未提供完整的指标、成本、token、告警和检索监控控制台。
- 没有登录、用户管理、角色切换或移动端适配承诺。

## 部署与评测

- 仓库未提供 Dockerfile、docker-compose、CI/CD、生产部署脚本或可启动 REST API 服务。
- FastAPI 已提供决策、审批、履约、记忆反馈与 Trace 路由，但一次决策仍由单个 HTTP 请求等待完成；尚无任务队列、异步作业状态机、JWT/OIDC 或多 worker 数据库架构。
- 离线评测代码和数据集存在于 `src/evaluation/`、`evals/`，但没有 UI 评测中心，也不是持续在线评测平台。

这些限制不否定项目作为本地业务工作流演示的价值；它们说明生产化前仍需要外部系统集成、身份权限、部署、监控和运营能力建设。
