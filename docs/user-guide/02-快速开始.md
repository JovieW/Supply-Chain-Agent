# 快速开始

## 环境要求

- 推荐 **Python 3.12**（项目 README 标注 Python 3.12+；仓库没有 `pyproject.toml` 进行强制版本校验）。
- 可访问 PyPI；首次使用本地 embedding 时还需下载 `BAAI/bge-small-zh-v1.5` 模型。
- 完整决策需要有效的 DashScope 或 OpenRouter LLM API Key。

## 最小启动：5 分钟查看静态演示

此模式完全离线，不读取 SQLite、不调用 LLM，也不验证审批或知识库。

```powershell
cd D:\SDU\lab\Multi-Agent-Supply-Chain-Control-Tower\Multi-Agent-Supply-Chain-Control-Tower
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
streamlit run demo/demo.py
```

浏览器打开 Streamlit 默认地址 `http://localhost:8501`。项目没有自行设置端口；如被占用，可改为：

```powershell
streamlit run demo/demo.py --server.port 8502
```

macOS/Linux 将前两行替换为：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

## 完整功能启动：本地决策工作台

1. 复制环境变量模板。

   ```powershell
   Copy-Item .env.example .env
   ```

2. 编辑 `.env`，至少填写一种 LLM 配置。默认是 DashScope：将 `DASHSCOPE_API_KEY` 改为有效 Key。若使用 OpenRouter，则设置 `LLM_PROVIDER=openrouter`、`OPENROUTER_API_KEY` 和可选的 `OPENROUTER_MODEL`。
3. 初始化本地数据库和示例业务数据。

   ```powershell
   python src/db_init.py
   ```

4. 构建企业知识库索引（首次、改知识文件或改 embedding 模型后执行）。

   ```powershell
   python -m src.rag.ingest --rebuild
   ```

5. 启动主界面。

   ```powershell
   streamlit run ui/app.py
   ```

6. 打开 `http://localhost:8501`，在左侧选择产品，点击“生成新方案”。

`ui/app.py` 运行前会初始化本地数据库；但没有 API Key 或知识索引时，页面可以打开，生成完整 Agent 方案会失败或降级，具体见[故障排查](12-故障排查.md)。

## Linux / conda 示例

```bash
conda create -n multiagent python=3.12 -y
conda activate multiagent
python -m pip install -r requirements.txt
cp .env.example .env
# 编辑 .env 后：
python src/db_init.py
python -m src.rag.ingest --rebuild
streamlit run ui/app.py
```

## 可选：写入演示闭环数据

以下脚本会在当前 SQLite 数据库写入固定的本地展示记录：一个已闭环反馈、一个仍可继续履约的采购单，以及一个已完成案例。它绕过 LLM 与审批，仅用于演示。

```powershell
python demo/seed_showcase_data.py
```

脚本需要 `.env` 中的 `MEMORY_FEEDBACK_USERS`，也可显式传入：

```powershell
python demo/seed_showcase_data.py --feedback-email planner@example.com
```

## 可选：命令行运行

```powershell
python src/main.py
```

它会对初始化的产品运行决策流程，需要 LLM 配置；若流程进入人工审批，推荐回到 Streamlit 的“审批任务”页面完成恢复，而不是把命令行当作审批客户端。

## Docker

当前仓库未提供 `Dockerfile` 或 `docker-compose.yml`，因此没有受支持的 Docker 启动命令。
