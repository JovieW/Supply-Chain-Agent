# 系统使用流程

主界面只有四个工作区：**决策工作台、审批任务、结果反馈、决策档案**。左侧选择的产品会决定本轮运行的业务对象。

## 一次完整业务闭环

```text
选择产品 → 生成新方案 → 查看建议和证据
                         ↓
                  风险门禁判断
                 ↙                 ↘
            自动本地执行          等待人工审批
               ↓                      ↓
          创建模拟采购单       批准后恢复并执行 / 拒绝结束
               ↓
确认供应商 → 发运 → 收货 → 质检 → 关闭采购单
                                       ↓
                         录入实际结果反馈 → 形成结果记忆
```

## 1. 打开并选择业务对象

进入页面后，在左侧“当前产品”下拉框选择：标准件 A（稳定需求）、高端件 B（波动需求）或专用件 C（高缺货风险）。页面读取的是本地 SQLite 的产品、库存、需求、供应商、在途和规则数据。

## 2. 生成方案

在“决策工作台”点击“生成新方案”或空白工作台中的“生成补货建议”。系统会读取实时快照、检索已发布的知识库、执行受限只读调查，随后给出确定性补货方案及 LLM 辅助解释。

用户应重点查看：建议动作、供应商、建议数量、风险等级、风险原因、业务影响、知识证据和运行记录。

> 生成方案需要可用 LLM。知识库索引不可用时，流程会尽量继续，但页面不会有可靠的知识证据；不是自动在运行时构建索引。

## 3. 判断执行状态

方案卡片会显示三类结果：

- **已执行**：通过规则门禁后，已在本地模拟采购适配器中创建采购单。
- **等待审批**：高风险或反思升级的方案已暂停，尚未创建采购单。
- **已阻断**：审批拒绝、过期或恢复前重新校验发现业务数据变化，需重新生成方案。

## 4. 审批高风险方案

打开“审批任务”，从待办列表选择任务并点击“打开任务”，查看计划、风险和有效期。具有服务端配置角色的本地审批人可填写意见后点击“批准并恢复执行”或“拒绝方案”。批准会从已保存的检查点恢复，并在执行前重新读取业务快照；拒绝则结束该方案。详细规则见[人工审批说明](07-人工审批说明.md)。

## 5. 跟踪采购履约

在“结果反馈”的“采购履约”区域选择活动采购单，按真实顺序更新：

`CREATED → SUPPLIER_CONFIRMED → SHIPPED → RECEIVED → QC_ACCEPTED / QC_REJECTED → CLOSED`

不同状态显示不同输入项：发运时填预计到货日，收货时填实际数量，质检时选择接受/拒绝。质检接受会把已接受数量计入本地库存；这仍是本地模拟，不会调用 ERP/WMS。

## 6. 录入实际结果并闭环

同一页的“实际结果反馈”只显示符合条件的执行记录：已有执行记忆、尚未反馈，且方案为 HOLD，或关联采购单已经 `CLOSED`。填写实际交期、到货量、缺货、质量拒收、实际成本、服务水平、反馈邮箱和备注，提交后状态成为 `OUTCOME_RECORDED`。后续新决策才有机会召回这些结果记忆。

若没有待反馈项，先检查采购单是否已关闭、执行记录是否关联采购单、反馈邮箱是否在 `MEMORY_FEEDBACK_USERS` 中；页面会给出诊断提示。

## 7. 查看历史与模拟

“决策档案”展示当前浏览器会话内刚生成方案的需求/库存趋势、供应商比较、审计记录，并提供只读情景沙盘。沙盘不会调用 Agent、不会改数据库；关闭页面或刷新后，当前方案可能需要重新生成。已闭环的历史结果在“结果反馈”历史区域查看。
