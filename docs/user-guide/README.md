# 供应链决策助手使用说明

本目录面向第一次使用项目的演示用户、开发者和评审者。文档按“先启动、再操作、再理解”的顺序编排；描述均以当前代码实际行为为准。

## 建议阅读顺序

1. [项目介绍](01-项目介绍.md)：先确认系统解决的问题与能力边界。
2. [快速开始](02-快速开始.md)：在本机打开页面。
3. [环境配置](03-环境配置.md)：配置 LLM、向量索引与本地数据。
4. [系统使用流程](04-系统使用流程.md)：完成一次从决策到反馈的闭环。
5. 按需查阅页面、Agent、审批、知识库和指标说明。

## 运行方式概览

| 模式 | 启动命令 | 是否需要 API Key | 能看到什么 |
|---|---|---:|---|
| 静态演示 | `streamlit run demo/demo.py` | 否 | 写死的示例页面；不连接数据库、LLM、RAG 或审批恢复 |
| 本地业务界面 | `streamlit run ui/app.py` | 初始化不需要；生成新方案需要 | 本地 SQLite 数据、采购履约、结果反馈、审批工作台 |
| 完整决策体验 | `streamlit run ui/app.py` + LLM + 已构建 RAG 索引 | 是 | Agent 分析、知识证据、只读工具、反思、审批与执行模拟 |

当前没有 Docker Compose、独立前端、Redis、独立 Vector DB 服务或可启动的 HTTP 后端服务。正常体验只需一个 Streamlit 进程；SQLite、LangGraph 检查点和 Chroma 索引均为本地文件。

## 状态图例

- **已实现**：当前代码中可运行的本地能力。
- **Demo / Mock**：用于展示的本地模拟，不会调用企业 ERP、WMS、SRM、TMS 或真实采购系统。
- **可选**：不配置也能使用部分页面，但会失去相应能力。
- **未提供**：当前仓库没有该功能或启动方式。
