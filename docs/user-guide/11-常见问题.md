# 常见问题

1. **页面地址是什么？** 运行 `streamlit run ui/app.py` 后访问 Streamlit 默认地址 `http://localhost:8501`；项目没有覆盖默认端口。

2. **只想看界面，需要 API Key 吗？** 不需要。运行 `streamlit run demo/demo.py` 可看静态演示；但它不是完整系统。

3. **为什么主页面能打开，但生成新方案失败？** 主页面可读取本地数据，完整工作流仍需要有效 LLM 配置。检查 `.env` 的 provider、Key 和模型名。

4. **能直接用千问/DashScope Key 吗？** 可以。设置 `LLM_PROVIDER=dashscope` 和 `DASHSCOPE_API_KEY`；不必使用 OpenRouter。

5. **一定要用 OpenRouter 吗？** 不需要。它仅是 `LLM_PROVIDER=openrouter` 时的可选 provider。

6. **为什么没有知识库证据？** 首次使用需执行 `python -m src.rag.ingest --rebuild`；确认知识文件 `status: active`、索引路径与 `.env` 一致。

7. **新增知识文件后为什么没有生效？** 应用不会自动重建索引。把文件放入 `data/knowledge/` 后执行 ingest，再重新运行方案。

8. **支持上传 PDF 吗？** 代码支持从知识目录读取 PDF/DOCX，但当前 UI 没有文件上传管理页；请通过文件系统放入目录并重新索引。

9. **为什么显示“等待审批”？** 本轮风险门禁或反思升级要求人工审核。它表示尚未创建采购单，不是系统卡死。

10. **批准后为什么仍没有采购单？** 恢复时会重新校验库存等快照；数据变化、审批过期或权限不符可能阻断旧方案。查看审批/运行记录后重新生成。

11. **谁能审批？** 本地服务端根据 `HITL_CURRENT_ACTOR_EMAIL` 与 `HITL_APPROVER_BINDINGS` 识别。UI 不能自行选角色。

12. **这是企业真实审批系统吗？** 不是。它有本地暂停和恢复链路，但身份、审批记录和采购执行均为本地演示实现。

13. **采购单创建后下一步做什么？** 去“结果反馈 → 采购履约”，按确认、发运、收货、质检、关闭的顺序更新状态。

14. **为什么没有“待反馈结果”？** 只有已执行、未反馈，且为 HOLD 或关联采购单已经 `CLOSED` 的记录才会出现。先关闭采购单，并检查页面诊断。

15. **采购履约和实际结果反馈有什么不同？** 履约记录订单执行过程；结果反馈评价最终业务效果（成本、交期、缺货、质量、服务水平）。

16. **怎样形成长期记忆？** 提交一次合格的实际结果反馈后，记录成为 `OUTCOME_RECORDED`；后续生成方案时才可能被召回。

17. **为什么反馈提交被拒绝？** 反馈邮箱必须包含在 `.env` 的 `MEMORY_FEEDBACK_USERS` 中，修改后重启应用。

18. **如何得到适合演示的闭环记录？** 运行 `python demo/seed_showcase_data.py --feedback-email planner@example.com`。这会改写本地数据库，仅用于 Demo。

19. **如何重新初始化数据？** 运行 `python src/db_init.py` 会初始化/补充默认数据，但不会承诺清空所有已存在的运行、采购和反馈历史。想完全重置，请先备份并谨慎处理 `data/supply_chain.db`。

20. **如何切换模型？** 修改 `.env` 的 provider 与对应模型变量，例如 `DASHSCOPE_MODEL` 或 `OPENROUTER_MODEL`，然后重启 Streamlit。

21. **如何查看运行日志？** 页面展开“方案依据与运行记录”，或查看 `AGENT_TRACE_PATH`（默认 `data/agent_traces.jsonl`）。该日志不存完整 prompt。

22. **如何停止项目？** 在启动 Streamlit 的终端按 `Ctrl+C`。

23. **有 Docker 启动方式吗？** 当前仓库没有 Dockerfile 或 Compose 文件，不提供 Docker 启动。

24. **有真正的 REST API 后端吗？** 有。运行 `python src/api_server.py` 启动 FastAPI；将 `UI_BACKEND_MODE=api` 后，Streamlit 会通过 HTTP 调用它。默认 `direct` 模式仍可在单进程中运行。

25. **能离线运行完整 Agent 吗？** 不能。完整流程的多处解释/反思/协调需要 LLM；离线可查看静态 Demo、初始化本地数据、管理已建索引或运行不依赖 LLM 的部分工具。

26. **为什么修改代码后页面没自动刷新？** 项目 `.streamlit/config.toml` 有意关闭文件监视，避免 transformers 可选依赖探测问题。请手动重启 Streamlit。
